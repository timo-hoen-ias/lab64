# Sammelobjekte

Generiert mit Scenario (Meshy T2.5 Smart Topology, Text-zu-3D), danach mit
`tools/shrink_glb.py` handytauglich gemacht: Textur 256 px (JPEG), matt,
Ursprung unten mittig, längste Kante auf Spielgröße skaliert (1 Einheit = 1 m).

Dateinamen = Schlüssel aus `FOOD` in `src/models.js` (goldbone, crumb, sausage, …).
